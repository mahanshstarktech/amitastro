Product Architecture

SpendMind Overview

Transforming raw, cryptic financial records into structured intelligence.

"SpendMind turns raw, cryptic bank-statement PDFs into clean, structured, and intelligently categorized financial transaction data."

It extracts text and tabular structures using pdfplumber, normalizes each line into Date, Narration, Amount, and Type via regex heuristics, and assigns merchants to expense categories using a hybrid Keyword Rules + TF-IDF ML Classifier. Results are stored in SQLite and served through FastAPI to an interactive web dashboard.

Market Need & Innovation

Problem Statement & Proposed Solution

Bridging the gap between locked banking documents and modern financial clarity.

The Problem

Friction Point
⚠️
PDF Document Lock-in
Bank statements arrive as locked, non-standard PDFs that cannot be queried or calculated directly.
⚠️
Manual Spreadsheet Drudgery
Tracking expenses manually in Excel or Google Sheets is tedious, time-consuming, and highly error-prone.
⚠️
Cryptic Bank Narrations
Strings like UPI-ZOMATO-9876543210 or POS-4482-AMZN are obscure and inconsistent.
⚠️
Zero Real-Time Cashflow Visibility
No quick, high-level visualization of where money is actually going without hours of manual sorting.

The SpendMind Solution

Engineered Fix
✓
Automated Layout Extraction
Headless extraction of text lines and tabular grids directly from PDF coordinates using pdfplumber.
✓
Structured Schema Normalization
Deterministic parsing into clean fields: Date, Clean Narration, Amount, and Type (Dr / Cr).
✓
Hybrid Categorization (Rules → ML)
Fast keyword heuristics combined with TF-IDF and Logistic Regression to classify novel merchants.
✓
Queryable Storage & Modern Dashboard

Technical Problem Solving

Engineering Challenges & Solutions

Real-world friction encountered during training and the pragmatic engineering remedies implemented.

PowerShell Execution Policy
Adjusted execution policy scope for process to activate virtual environment without admin overrides.
Unicode Font Encoding in PDF
Resolved ReportLab encoding errors by standardizing Type-1 font mappings for reliable statement generation.
Non-Deterministic PDF Output
Pinned creation date timestamps and metadata headers to produce byte-identical fixtures on every run.
Windows Git Global Config Conflict
Isolated repository credentials using local Git configs (git config --local) to ensure clean pushes to GitHub.
Competing Extractor Prototypes
Benchmarked multi-algorithm outputs and merged the most resilient bounding-box extraction logic into one tested module.
