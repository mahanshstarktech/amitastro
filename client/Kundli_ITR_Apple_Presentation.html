Bridging classical astronomical science with modern cloud engineering and artificial intelligence.

“Amit Astro turns birth coordinates and timestamps into sub-second mathematical ephemeris calculations, predictive dasha timelines, and real-time live consultations.”

Technical Problem Solving

Engineering Challenges & Solutions

Key obstacles encountered during the project implementation and the robust architectural solutions applied.

PostgreSQL vs SQLite Identifier Variance
Postgres treated double quotes as column identifiers causing runtime crashes; resolved by parameterizing all SQL literals.
Astronomical Ephemeris Coordinate Drift
Standard algorithms drifted over leap years; calibrated against Chitra Paksha Lahiri Ayanamsha for sub-0.01° precision.
WebSocket Mobile Drop-off Reconnection
Mobile browser tab suspensions terminated chats; implemented heartbeat keep-alives and state rehydration on reconnect.
Payment Webhook Integrity & Tampering
Prevented subscription spoofing using cryptographically signed HMAC-SHA256 signature verification on Razorpay events.
AI Hallucinations in Astrological Readings
Grounded LLM prompts with Parashari shastra rulebooks and structured JSON schemas to ensure canonical remedies.
